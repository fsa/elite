# Проект Elite на Rust

В качестве базы сейчас используется эмуляция Z80. При портировании должны использоваться прослойки, которые потом можно будет заменить нативным кодом по мере необходимости.

Кнопки управления должны изначально остаться из оригинала. Новые функции будут добавлены на кнопках, которых нет на ZX-Spectrum (например, F1-F12).

## Исходные коды игры и сама игра

В папке kladov в корне проекта AI-разбор кода игры из kladov.snapshot, который можно использовать для упрощения портирования игры на нативный код.

Имеющиеся исходные файлы для ZX:

- ELITE3HL.TRD — образ дискеты TR-DOS так называемой версии Elite 3 автора Кладова, которая включает дополнительные миссии и некоторые изменения интерфейса игры, может не полностью соответствовать дизасемблированной версии;
- kladov.snapshot — снапшот эмулятора fuse для ELITE3HL.TRD созданный сразу после запуска игры.

## Временные файлы

Для временных файлов (дампы памяти, эталонные кадры для сравнения графики,
тосты CPU, скачанные тестовые бинари и т.п.) используется папка `tmp/` в корне
проекта. Всё её содержимое игнорируется гитом (кроме самого `tmp/.gitignore`).
Временные файлы складывать сюда, а не во внешние каталоги вроде `/tmp`.
