# Проект Elite на Rust

В качестве базы сейчас используется эмуляция Z80. При портировании должны использоваться прослойки, которые потом можно будет заменить нативным кодом по мере необходимости.

Кнопки управления должны изначально остаться из оригинала. Новые функции будут добавлены на кнопках, которых нет на ZX-Spectrum (например, F1-F12).

## Исходные коды игры и сама игра

В папке kladov в корне проекта AI-разбор кода игры из kladov.snapshot, который можно использовать для упрощения портирования игры на нативный код.
