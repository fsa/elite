# Проект Elite на Rust

В качестве базы сейчас используется эмуляция Z80. При портировании должны использоваться прослойки, которые потом можно будет заменить нативным кодом по мере необходимости.

Кнопки управления должны изначально остаться из оригинала. Новые функции будут добавлены на кнопках, которых нет на ZX-Spectrum (например, F1-F12).

## Нативные альтернативные экраны

- Экраны на `F1`–`F10` — такие же экраны, как и другие экраны игры, но с нативной (альтернативной) отрисовкой/реализацией.
- При открытии альтернативного экрана в эмуляторе должен включаться экран с таким же функционалом (то же состояние/режим Z80, те же данные), чтобы логика игры оставалась согласованной.
- Перехват ввода нужен только в отдельных нативных экранах, где есть собственный интерактив, не управляемый эмулятором (например, нативная карта галактики с курсором/выбором). Только необходимые для такого интерактива клавиши/события следует перехватывать; остальные — передавать эмулятору, если экран должен вести себя как оригинальный.
- Для экранов без собственного интерактива нативная реализация — в первую очередь альтернативное отображение; управление должно оставаться за эмулятором/оригинальными клавишами, насколько это соответствует функционалу экрана.

## Исходные коды игры и сама игра

В папке kladov в корне проекта AI-разбор кода игры из kladov.snapshot, который можно использовать для упрощения портирования игры на нативный код.

## Структура управления

Сейчас проект представляет из себя нативный код и эмуляцию Z80. Нативный код важнее, чем эмуляция. Он должен чётко отрабатывать. При этом при своей работе он может посылать команду эмулятору и использовать его данные в некоторых режимах. При этом данные никогда нельзя брать непосредственно из эмулятора, только через прослойку состояния игры или другие прослойки, если такие будут.
