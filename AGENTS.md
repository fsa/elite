# Проект Elite на Rust

Этот проект — попытка портировать игру Elite модификации Кладова (т.н. Elite 3) с компьютера ZX-Spectrum. Конечная цель — полностью уйти от эмуляции Z80 и сделать полноценную игру на Rust, которая должна повторять все геймплейные механики игры, миссии и баги (сохранить логику полёта в космосе максимально близко к оригиналу), но иметь улучшенный интерфейс и графику.

На начальных этапах разрешено использовать эмуляцию Z80 для быстрого запуска игры. Проект будет считаться завершённым, когда будут удалены последние зависимости эмуляции Z80.

В финале работа с графикой должна быть полностью переведена на современные технологии. Графика должна быть довольно примитивной, используя знакомые образы из оригинала. Но корабли должны обрести объём и не быть прозрачными. Также неплохо использовать освещение, которое должно зависеть от местоположения звезды. Планета должна стать непрозрачной.

Кнопки управления должны изначально остаться из оригинала, но нужно сделать подсказки. Позже, управление должно быть полностью переделано с учётом современных способов управления.

## Исходные коды игры и сама игра

В папке kladov в корне проекта AI-разбор кода игры из kladov.bin, который можно использовать для упрощения портирования игры на нативный код.

В папке `zx_src` расположены исходные коды игры, полученные путём дизасемблирования. Игра имеет несколько вариантов, но они все базируются на оригинальной версии игры. Поскольку исходного кода игры у модификаторов не было, то основная часть игры осталась без изменений и занимает одинаковые адреса.

Имеющиеся исходные файлы:

- elite.asm — дизасемблированный код игры с комментариями;
- elite.idb — метаданные дизассемблера для elite.asm;
- kladov.asm — дизасемблированный код игры версии Кладова с комментариями;
- kladov.idb — метаданные дизассемблера для kladov.asm;
- ELITE3HL.TRD — образ дискеты TR-DOS так называемой версии Elite 3 автора Кладова, которая включает дополнительные миссии и некоторые изменения интерфейса игры, может не полностью соответствовать дизасемблированной версии;
- kladov.snapshot — снапшот эмулятора fuse для ELITE3HL.TRD созданный сразу после запуска игры, можно использовать для быстрого запуска fuse или извлечь необходимый машинный код.

## Временные файлы

Для временных файлов (дампы памяти, эталонные кадры для сравнения графики,
тосты CPU, скачанные тестовые бинари и т.п.) используется папка `tmp/` в корне
проекта. Всё её содержимое игнорируется гитом (кроме самого `tmp/.gitignore`).
Временные файлы складывать сюда, а не во внешние каталоги вроде `/tmp`.
