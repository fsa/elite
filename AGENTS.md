# Проект Elite на Rust

Этот проект — попытка портировать игру Elite с компьютера ZX-Spectrum. Конечная цель — полностью уйти от эмуляции Z80 и сделать полноценную игру на Rust.

На начальных этапах разрешено использовать эмуляцию Z80 для быстрого запуска игры. Проект будет считаться завершённым, когда будут удалены последние зависимости эмуляции Z80. Игра должна сохранить основные особенности оригинала, но разрешено улучшать непосредственно игровой процесс с полётом в космосе.

В финале работа с графикой должна быть полностью переведена на современные технологии (пока не выбраны). Графика должна быть довольно примитивной, используя знакомые образы из оригинала. Но корабли должны обрести объём и не быть прозрачными. Также неплохо использовать освещение, которое должно зависеть от местоположения звезды. Планета должна стать непрозрачной.

Кнопки управления должны изначально остаться из оригинала, но нужно сделать подсказки. Позже, управление должно быть полностью переделано с учётом современных способов управления.

В идеале нужно воспроизвести поведение версии игры с модификациями Кладова.

## Исходные коды игры и сама игра

В папке `zx_src` расположены исходные коды игры, полученные путём дизасемблирования. Игра имеет несколько вариантов, но они все базируются на оригинальной версии игры. Поскольку исходного кода игры у модификаторов не было, то основная часть игры осталась без изменений и занимает одинаковые адреса.

Имеющиеся исходные файлы:

- elite.asm — дизасемблированный код игры с комментариями;
- elite.idb — метаданные дизассемблера для elite.asm;
- kladov.asm — дизасемблированный код игры версии Кладова с комментариями;
- kladov.idb — метаданные дизассемблера для kladov.asm;
- ELITE3HL.TRD — образ дискеты TR-DOS так называемой версии Elite 3 автора Кладова, которая включает дополнительные миссии и некоторые изменения интерфейса игры, может не полностью соответствовать дизасемблированной версии;
- kladov.snapshot — снапшот эмулятора fuse для ELITE3HL.TRD созданный сразу после запуска игры, можно использовать для быстрого запуска fuse или извлечь необходимый машинный код.

## Временные файлы

Для временных файлов (дампы памяти, эталонные кадры для сравнения графики,
тосты CPU, скачанные тестовые бинари и т.п.) используется папка `tmp/` в корне
проекта. Всё её содержимое игнорируется гитом (кроме самого `tmp/.gitignore`).
Временные файлы складывать сюда, а не во внешние каталоги вроде `/tmp`.

## Детали реализации

Из жёстких требований — игра должна быть реализована на Rust. Необходимые библиотеки и прочее будут выбраны по ходу портирования игры.

## Что из себя представлял ZX-Spectrum

Память компьютера делилась на несколько блоков:

0000:3FFF — ПЗУ с прошивкой;
4000:FFFF — ОЗУ.

В ОЗУ выделяется область 4000-1BFF — видеопамять. По сути картинка чёрно-белая, но последни блок видеопамяти указывает на цветовые атрибуты знакоместа 8х8. Таким образом можно задать цвет для блоков 8х8, где 0 и 1 — это два разных цвета.

Для машин со 128КБ или более, в ОЗУ блок C000-FFFF использовался для переключения страниц. После записи в порт ввода вывода номера страницы, страница памяти переключалась и отображалась на этих адресах.
