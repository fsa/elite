# Файл сохранения

## Общие сведения

- Размер файла: **102 байта (`0x66`)**.
- Диапазон смещений: `#00–#65`.
- Отдельной контрольной суммы в блоке нет.
- Формат: последовательность байтов без шифрования.
- Основной блок соответствует структуре `PilotName`.
- При сохранении последние 9 байт (`#5D–#65`) обновляются из `SunCrd` и содержат данные солнца.
- Координаты курсора карты `Pilot_CrdXTarget` и `Pilot_CrdYTarget` в файл не входят.

## Карта данных

| Смещение | Длина | Назначение |
| --- | ---: | --- |
| `#00–#0A` | 11 | Имя пилота (`PilotName`). ASCII, до 10 символов, завершающий `0x00`. |
| `#0B` | 1 | Правовой статус (`PilotLegalStatus`). `0` — чистый статус. |
| `#0C–#0E` | 3 | Область рейтинга и статусных флагов (`PilotRating0..2`). Включает биты миссий, войны и ранга. Точная семантика отдельных битов требует уточнения. |
| `#0F–#13` | 5 | Служебные поля и дополнительные данные командира. Точная раскладка пока не установлена. |
| `#14–#17` | 4 | Деньги (`PilotCash*`). Беззнаковое 32-битное Little Endian, десятые доли кредита. Например, `E8 03 00 00` = 1000 = 100,0 Cr. |
| `#18–#27` | 16 | Данные груза и связанные служебные поля. Включают счётчики товаров и другие параметры грузового отсека. Точное соответствие каждому байту требует уточнения. |
| `#28` | 1 | Базовая вместимость грузового отсека (`PilotFreeCargo`). Начальное значение `0x14` = 20 т. |
| `#29` | 1 | Носовой лазер (`PilotFrontLaser`). |
| `#2A–#2D` | 4 | Дополнительные слоты вооружения, включая боковые и кормовой лазеры. Точное соответствие байтов требует проверки. |
| `#2E` | 1 | Запас топлива (`Pilot_Fuel`). Десятые доли светового года. `0x46` = 70 = 7,0 LY. |
| `#2F` | 1 | Количество ракет (`PilotMissiles`). |
| `#30–#3B` | 12 | Оборудование и служебные флаги: грузовой отсек, ECM, Alien Computer, Mineral Life, Fuel Scoops, Escape Pod, Energy Bomb, Docking Computer, гипердвигатель и другие параметры. Точное побайтовое соответствие требует уточнения. |
| `#3C–#41` | 6 | Данные галактики и планеты (`PilotGalaxyData0`, `PilotPlanetData`). |
| `#42` | 1 | Дополнительные данные планеты. Точное назначение не установлено. |
| `#43` | 1 | Координата Y текущей звёздной системы (`Pilot_CrdYSystem`). |
| `#44` | 1 | Служебные данные текущей системы/планеты. Точное назначение не установлено. |
| `#45` | 1 | Координата X текущей звёздной системы (`Pilot_CrdXSystem`). |
| `#46–#5C` | 23 | Данные текущей планеты, параметры экономики, миссии, война и расширенное вооружение. Включают `PilotPlanetTechLvl`, `PilotPlanetGov`, `PilotPlanetProduct`, `PilotTargonWar`, `PilotMission1/3`, `PilotMission1_1`, `PilotExtWeapon` и другие поля. Полная побайтовая раскладка требует уточнения. |
| `#5D–#65` | 9 | Данные солнца (`PilotDataOfSun`). При сохранении копируются из `SunCrd`. |

## Примечания

- Смещения указаны относительно начала 102-байтового блока.
- Начальные значения соответствуют начальному образу командира Jameson (`aJameson_1`).
- Области, для которых не установлено точное соответствие байтов переменным, описаны укрупнённо.
- Координаты курсора карты `Pilot_CrdXTarget` и `Pilot_CrdYTarget` расположены по смещениям `+0x67` и `+0x68` относительно `PilotName` и не входят в файл сохранения.
- Передача блока выполняется через `MenuSaveLoad2`, `sub_D91A` и `byte_C800`.
