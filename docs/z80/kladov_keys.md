# Клавиши управления в режиме паузы в версии Кладова

При нажатии Left Shift включается пауза. В этом режиме работают следующие настройки:

- Y — инверсия управления вверх/вниз
- B — инверсия управления: задний экран управляется как передний
- D — инверсия управления: левый/правый экран управляется как передний
- C — переключение компаса: Планета / Станция → Планета + Солнце
- L — переключение локатора
- A — поворот лазеров Cobra Mk IV на два крепления
- K — поворот станины лазеров на карте
- R — поворот станины лазеров Cobra Mk IV по часовой стрелке
- F — режим поиска таргонов при гиперпереходе (?)
- Q — выключить звук
- S — включить звук
- Space — выход из паузы

В нативном режиме паузы на каждую сервисную клавишу и на вход в паузу даётся короткий звуковой отклик: эмулятор заморожен, поэтому подтверждение синтезируется нативным слоем.
