# Клавиши управления в режиме паузы в весии Кладова

При нажатии Left Shift включаетс пауза. В этом режиме работают следующие настройки:

- Y — Инверсия управления вверх/вниз
- B — Инверсия управления: задний экран управляется как передний
- C — Переключение компаса: Планета / Станция → Планета + Солнце
- L — Переключение локатора
- R — Поворот станины лазеров Cobra MK4 по часовой стрелке
- F — Режим поиска таргонов при гиперпереходе (?)
- Q — Выключить звук
- S — Включить звук
- Space — Выход из паузы
