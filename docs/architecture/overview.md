# Обзор архитектуры

Проект переносит Elite для ZX Spectrum на Rust, сохраняя оригинальную игровую логику и постепенно заменяя отдельные графические элементы нативной реализацией.

## Основные части

- Оригинальная игровая логика выполняется Z80-эмуляцией.
- Нативные экраны и графические эффекты отображаются через слой `display::Frame`.
- Общая логика отрисовки 3D-объектов вынесена в `src/render3d/`.
- Данные моделей кораблей находятся в `src/shipdata.rs` и отдельных файлах `src/shipdata/`.
- Инструмент извлечения геометрии из образа игры находится в `tools/extract_ships.py`.

## Граница ответственности

Нативная графика отвечает за отображение и визуальные эффекты. Оригинальная игровая логика остаётся источником игрового поведения, если отдельно не оговорено иное.
