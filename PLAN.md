## Текущие баги

Список очищается по мере устранения.

- Скорость движения звёзд пропорционально ниже, чем в оригинале. Нужно подобрать скорость по отзывам пользователя, а не анализировать код.

## Что ещё нужно сделать

- [~] Доработать кокпит, добавить радар. Сейчас невозможно ориентироваться в пространстве в нативном движке.
- [ ] Взять шрифт, используемый игрой и перевести его в rust-код. Скорее всего игра использует стандартный шрифт ZX из 48.rom. Нужно отвязаться от образа ROM и сделать отрисовку текста нативным.
- [ ] Информационные сообщения. Обычно они высвечиваются внизу экрана. Нужно сделать отдельную функцию управлением сообщением внизу экрана. Сейчас уже есть сообщение о гиперпрыжке. Нужно сделать так, чтобы можно было публиковать любое сообщение, которое выдаёт игра.
- [ ] Слышны щелчки в аудио при работе эмулятора (вероятно связано с 1/0 на бипере).
- [ ] Звёзды в полёте концентрируются в центре экрана, по краям пустота.
- [ ] Скорость перемещения звёзд не даёт ощущение о реальной скорости.
- [ ] При использовании кнопки J для ускорения полёта звёзды вообще не ускоряются.

## Конечная цель

- [ ] Удалить последние зависимости эмуляции Z80.
