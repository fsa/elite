# План портирования Elite (ZX Spectrum) на Rust

Цель проекта — в `AGENTS.md`. Здесь пошаговый план работ. Перед началом реализации пунктов плана необходимо поставить отметку, что они в работе.

Задави выполнять строго по одной (если нельзя связать две задачи, которые относятся к одному коду). После каждого исправления ждать результатов тестирования человеком.

Когда для задачи нужно анализировать исходные коды оригинальной игры, дополняй комментариями то, что смог разобрать.

## Текущие задачи

- [x] На странице EQUIP SHIP отображается бак с топливом сколько есть и сколько всего, а грузовой отсек только сколько свободного. Лучше отображать сколько есть и сколько всего, как топливо.

## Комплексные баги, найденные во время игры

- [ ] У компаса до сих пор больше 4 нормальных режимов: указатель на станцию, указатель на планету, указатель на планету+солнце и указатель на то, как между звёзд ориентироваться. Я видел смесь режимов межзвёздного и планета+солнце. Этого быть не должно.
- [~] На станции до сих пор работает неадекватно F1. После приземления вместо вылета со станции он показывает полёт. И только второе нажатие даёт нужный результат.
- [x] При покупке лазера нельзя его выбрать стрелками, нужно нажимать 0-3. Лучше нажимать 1-4, а также сделать типовой выбор с выделением как на других страницах (маркет, оборудование, сохранение и т.д.)
- [x] При вылете со станции отображается фантомная картинка космоса. Нужно в конце анимации вылета копировать реальное состояние и уже потом передать управление рендеру. Иначе там хранится старая картинка.
