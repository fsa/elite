## Что ещё нужно сделать

- [x] Почистить вывод --help. Оставить там только опции комнатной троки при запуске файла. Документацию об управлении нужно размещать в файле README.
- [x] Файл загрузки нужно передавать непосредственно в виде аргумента (не -- и не - параметра). Параметр необязательный.
- [~] Добавить защиту при загрузке файлов с сохранениями (командная строка и импорт). Файл должен начинаться обязательно с имени пилота и байта 00 в конце (см. документацию). Если файл другой длины, не 102 байта и нет имени пилота  разделителем 0x00, то просто выдавать ошибку и не запускаться, либо выводить предупреждение, что файл не может быть импортирован. Проверка должна быть в одном экземпляре в коде, чтобы её можно было доработать.
