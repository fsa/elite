# Структура разбора kladov.bin/kladov.asm

Весь код разбит по функциональным блокам для поэтапного переноса на другую платформу с сохранением геймплея.

## Структура по каталогам
- 01_start_init/ - инициализация игры, старт
- 02_input_keyboard/ - ввод с клавиатуры
- 03_game_loop/ - основной игровой цикл
- 04_movement_physics/ - движение, повороты, физика
- 05_collision_damage/ - столкновения, урон, уничтожение
- 06_objects_render/ - отрисовка объектов/кораблей
- 07_3d_projection/ - 3D проекция, вершины, векторы
- 08_radar_scanner/ - радар/сканер, компас
- 09_drawing_primitives/ - примитивы рисования, линии, пиксели
- 10_circles_planets/ - круги, солнце, планеты
- 11_combat_lasers/ - лазеры, ракеты, оружие
- 12_docking/ - стыковка
- 13_hyperspace/ - гиперпереходы
- 14_galaxy_map/ - галактическая карта
- 15_trading_equip/ - торговля, снаряжение
- 16_missions/ - миссии, война Таргонов
- 17_save_load/ - сохранение/загрузка
- 18_text_print/ - вывод текста
- 19_sound/ - звук
- 99_misc/ - прочие подпрограммы

Каждый каталог содержит файл `XX_*.asm` со всеми подпрограммами данного блока, извлечёнными из kladov.asm с сохранением оригинальных меток и кода.

Также сохранены детальные фрагменты в корне kladov/ (00-05, 10-23) для удобства изучения.
