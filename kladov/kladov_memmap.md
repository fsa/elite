# Карта памяти kladov.bin

Bin = page5(4000-7FFF) + page2(8000-BFFF) + page0(C000-FFFF), итого 49152 байт.

## 4000-47FF
В основном нули. Вероятно видеопамять/буферы не в этом блоке или заполнены нулями в данном образе.

## 4800-5BFF
Есть данные таблиц (4800, 4A00, 4C00, 4E00 - похоже на таблицы/атрибуты/данные).
5A00-5BFF: заполнено 07 07 ... (атрибуты?)
5C00-5CFF: служебные данные/таблицы

## 5D00-5FFF - служебная область
Согласно kladov.asm org 5D00h. Содержит данные игры:
- 5D00: заголовок/данные (1F FF FC ...)
- 5C00+: таблицы
- 5D60+: маски/таблицы
- 5DC0+: возможно данные
- 5E00+: начинает попадать код (видны CALL/JR/JP паттерны)

В kladov.asm с ~line 68 начинается segment RAM org 5D00h с данными, позже идёт код.

## 6000-7FFF - код и данные
Много кода/данных. Здесь находятся подпрограммы из kladov.asm.

## 8000-BFFF (page2)
Код/данные. Обращения к кругам/рисованию часто в этой области.

## C000-FFFF (page0)
Есть таблица переходов в начале C000 (jmp table?), данные, стековая область?
C000: FF FF ... похоже на таблицу
D000: C3 AE E6 C3 ... - таблица переходов
E000, F000 - данные/код

## Примечания
- В оригинальном Elite память размечена иначе, у Кладова своя раскладка
- Служебные области перемешаны с кодом
- Для полного понимания нужно сопоставлять с адресами из kladov.asm

## Статистика CALL
- 5E00-6FFF: ~60 вызовов (переходная зона)
- 7000-BFFF: много кода (400+ вызовов) - основная кодовая область
- C000-FFFF: D000-EFFF активно, C000 чистые данные/таблицы
- 4000-5DFF: данные/видеопамять/служебные

Судя по всему, **основной код игры** расположен в диапазонах 6000-BFFF и частично D000-FFFF.
