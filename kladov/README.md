Разбор кода версии Кладова на Z80 ассемблер.

## Новая основа (128K)

- `kladov128.asm` — полный листинг, перегенерированный из `zx_bin/kladov128.bin`.
- `disassemble128.py` — генератор (`python3 -m pip install --user z80dis`).

Соответствие банков: bank 5 → `4000h`, bank 2 → `8000h`, bank 0 → `C000h`.
Дополнительные банки 1, 3, 4, 6, 7 выведены в конце файла.

При генерации сохранены все найденные имена, метки и комментарии из
`zx_src/kladov.asm`: для неизменившихся байтов строки переносятся дословно,
изменившиеся и ранее неразобранные участки дизассемблируются заново и
помечаются `; ИЗМЕНЕНО` / `; Неразобранный участок`. Адреса меток
проверены по 1762 якорям вида `loc_XXXX`/`sub_XXXX`/`j_XXXX` — все совпадают.

## Старый разбор (48K)

Основан на дизассемблированном `kladov.asm` из `zx_src/` с проверкой
соответствия `kladov.bin` (`zx_bin/kladov.bin`).
Файлы разбиты по функциональному назначению для удобства переноса на другие платформы.

Радара и отображение кругов — приоритетный фокус разбора.
