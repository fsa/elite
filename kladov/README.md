Разбор кода версии Кладова (kladov.bin) на Z80 ассемблер.

Основан на дизассемблированном kladov.asm из zx_src/ с проверкой соответствия kladov.bin (zx_bin/kladov.bin).
Файлы разбиты по функциональному назначению для удобства переноса на другие платформы.

Радара и отображение кругов — приоритетный фокус разбора.
