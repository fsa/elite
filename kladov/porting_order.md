# Порядок портирования (по зависимостям)

Цель - переносить блоками, минимизируя зависимости. Основан на графе вызовов и структуре кода.

## Этап 0: Инфраструктура
- [ ] Эмулятор/движок - уже есть в src/z80.rs, machine.rs (для сравнения)
- [ ] Память, экраны, ввод
- [ ] Примитивы вывода

## Этап 1: Данные и инициализация
- [ ] **01_start_init** - InitGame, начальные данные
- [ ] Данные кораблей/галактики (можно вынести отдельно)
- [ ] **18_text_print** - вывод текста (нужен почти везде)

## Этап 2: Базовые системы
- [ ] **07_3d_projection** - математика проекции (критично)
- [ ] **04_movement_physics** - движение/повороты
- [ ] **09_drawing_primitives** - линии/пиксели

## Этап 3: Отрисовка и объекты
- [ ] **10_circles_planets** - солнце/планеты/круги
- [ ] **06_objects_render** - отрисовка кораблей
- [ ] **08_radar_scanner** - радар/сканер

## Этап 4: Игровой цикл и взаимодействие
- [ ] **03_game_loop** - основной цикл
- [ ] **02_input_keyboard** - управление
- [ ] **11_combat_lasers** - оружие
- [ ] **05_collision_damage** - столкновения/урон

## Этап 5: Места и перемещения
- [ ] **12_docking** - стыковка
- [ ] **13_hyperspace** - гиперпереходы
- [ ] **14_galaxy_map** - карта галактики

## Этап 6: Экономика и миссии
- [ ] **15_trading_equip** - торговля/снаряжение
- [ ] **16_missions** - миссии Кладова
- [ ] **17_save_load** - сохранение

## Этап 7: Прочее
- [ ] **19_sound** - звук
- [ ] **99_misc** - остальное по мере необходимости

## Рекомендации
- Начинать с 3D-математики + проекции - это основа всего
- Радар/круги важны для понимания, но не блокируют базовый движок
- Тестировать поэтапно, сравнивая с поведением в эмуляторе
- Кладовские правки в миссиях/интерфейсе учесть отдельно
