# Конвейер от модели до экрана

## 1. Данные модели
- ShipData содержит указатели на таблицы вершин/рёбер/нормалей (dVertex, dEdge, dNormal)
- Вершины хранятся в координатах модели
- Рёбра определяют линии для отрисовки

## 2. Движение/ориентация
- MoveAllObjects/ReactionObject/DirectObject/MoveObject обрабатывают движение
- Углы поворота хранятся в слотах объектов (oTurnLR, oTurnDU)
- Скорость, импульс и т.п.

## 3. Проекция в экранные координаты
- GetCrdsProjection - получение координат и знаков проекции объекта
- SetCrdCDEinExtSlot - установка координат в расширенном слоте
- Проекция 3D -> 2D с учётом перспективы

## 4. Подготовка вершин для отрисовки
- MakeTablPrnCrdVertex - построение таблицы координат вершин для печати
- CalcPrnCrdVertex - расчёт экранных координат вершины
- GetPrnCrdVertex - получение координат вершины

## 5. Отрисовка
- PrnObjIfVisible - проверка видимости и отрисовка объекта
- objPrnObj - отрисовка объекта
- PrnLineInBuf_clip - отрисовка линий с клиппингом
- objPrnLaser - отрисовка лазера
- PrnCircle_Fill/NoFill/Clip - круги (солнце, планеты, эффекты)

## 6. Вывод на экран
- Очистка буфера, вывод в видеопамять
