# Углублённый разбор ядра Elite (Кладов)

Фокус на том, что нужно для переноса: 3D-математика, проекция, объекты, движение, отрисовка.

## Структура
- projection/ - проекция, математика 3D
- objects/ - SlotObj, ShipData, работа со слотами
- movement/ - движение, повороты, физика
- render/ - отрисовка линий, объектов, кругов
- math/ - тригонометрия, таблицы
- structs.md - структуры данных
- data_tables.md - таблицы данных
- pipeline.md - конвейер от модели до экрана
